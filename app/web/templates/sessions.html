How To Create A Session File

Run the login capture on a computer where a browser can open, sign in to the competitor site, then upload the generated JSON file here. Treat that file like a password.

.\.venv\Scripts\python.exe auth_bootstrap.py --competitor partzilla

The file will be created under data/private. Upload the matching competitor JSON file here, then Part Pulse can reuse that saved sign-in on the server.
