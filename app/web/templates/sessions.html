How To Create A Session File

For normal price checks, refresh the login on the same computer that runs the Desktop Collector. Open Refresh Partzilla Login.cmd, sign in, then press Enter in the command window after the site shows you are signed in.

.\Refresh Partzilla Login.cmd

The file is saved under data/private. Treat it like a password. Uploading the JSON here is useful as a server-side backup, but it does not replace the desktop collector login when checks run on your computer.
